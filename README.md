# Техник — интернет-магазин инструментов (Котлас)

Премиальный интернет-магазин для оффлайн-магазина «Техник» (просп. Мира, 28, Котлас,
+7 (950) 250-62-30). Стек — Next.js 16 / React 19 / Tailwind v4 / `pg` без ORM,
по образцу сиблинг-проектов (`globus-kotlas-site` и др.) на том же сервере.

## Статус фазы

Рабочий прототип: каталог, карточка товара, корзина (localStorage), демо-оформление
заказа (без онлайн-оплаты — эквайринга у магазина пока нет), заявки на прокат
инструмента, простая админка (один пароль из `ADMIN_PASSWORD`) с товарами,
импортом из CSV-выгрузки 1С, журналом изменений, заказами и заявками.

Стаб/не реализовано: личный кабинет (только заглушка), боты Telegram/VK/MAX
(см. `docs/BOTS_TODO.md`), реальная синхронизация с 1С по сети (у кассы нет
интернета — работает только ручная загрузка CSV).

## Быстрый старт

```bash
npm install
cp .env.local.example .env.local   # заполнить DATABASE_URL, ADMIN_PASSWORD, ADMIN_SESSION_SECRET
npm run migrate
npm run seed      # категории + 2 реальных демо-товара через импорт-пайплайн
npm run dev
```

## Импорт из 1С

`/admin/import` — загрузка CSV-выгрузки (формат в `docs/sample-imports/example_1c_export.csv`).
Идентичность товара между импортами — `onec_id` (GUID номенклатуры), не имя и не артикул.
Товары с ручной правкой (`manual_override` или защищённые поля) импорт не перезапишет,
кроме остатка — остаток всегда приходит с кассы. Подробности — `db/migrations/0001_init.sql`
и `src/server/import/run.ts`.
